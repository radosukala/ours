## The problem

Every article of the constitution declares how it is actually held, and
the document says of itself that a class is "a fact about this repository,
not an aspiration." Five class lines are not facts:

| Article | The class line says | What the kernel does |
|---|---|---|
| `R-PUBLIC-PRIVATE` | `ENFORCED` · *kernel: no field marked private in a public projection* · `CHECKED` for secret-shaped strings in receipts | neither check has ever existed in Kernel 0.1's rule list. What holds: a community's register is private by placement (never in the repository); a specification's contract lists the fields an application may reach; and, since `M-0006`, a disclosure of an undeclared field is refused at the gate |
| `R-EXACT-ARTIFACT` | `ENFORCED` at the release gate for digest equality | no release gate exists; the one release so far was compared by a person, once, and receipted as `CHECKED` |
| `R-NO-FICTIONAL-OWNERSHIP` | `ENFORCED` · *kernel: prohibited-claim check* | the kernel classes its own finding `CHECKED`, because a pattern scan cannot read polarity — and flagged a denial as an assertion on its first run (`M-0001` receipt) |
| `R-TRUTHFUL-STATUS` | `CHECKED` for whether the state asserted matches the evidence | no such check exists; what now exists, since `M-0004`, is stronger than the line says — adoption is `ENFORCED` |
| `R-SOURCE-HIERARCHY` | `ENFORCED` for the ordering of recorded sources | true, and incomplete: prerequisite decisions are `ENFORCED` since `M-0004` and unmentioned |

Three lines claim more than holds; two claim less. The predecessor
project's lesson (`AGENTS.md` §10) was that provenance was enforced and
accuracy was not; this is the same lesson at the level of the constitution
describing itself.

## Affected

Anyone who reads the constitution to learn what holds. Agents, which are
told never to describe a `DECLARED` rule as enforced and inherit the
document's own errors.

## Requested decision — `D-0009`, CONSTITUTIONAL

1. **Amend the five class lines** to what holds, article by article, with
   the text in `D-0009`. The article bodies do not change.
2. **Authorize `M-0008`, BUILD:** a conformance test that fails when an
   article's class line names a kernel rule that no finding carries, and
   an `ours articles` report that prints every article's declared class
   beside the kernel's actual class for the last run — so that this
   drift is caught by a machine next time rather than by a person writing
   a report; and, while in `apps/proof`, replace its private copy of the
   article parser with the kernel's, which `M-0006` had to duplicate
   because that path was denied.

## Alternatives considered

| Option | Counter-case |
|---|---|
| leave the lines as they are | they are false, in the document whose purpose is truthfulness |
| downgrade every uncertain line to `DECLARED` | an over-correction: two of the five now hold *more* strongly than written, and saying less than holds is the same error in the other direction |
| build the missing checks instead of relabelling | a private-field projection check needs a notion of private fields the records do not yet carry; a release gate needs a deploy pipeline. Both are later mandates' work; a label must be true today |
| fix the lines without a decision | `R-AMENDMENT` requires a decision naming the articles and the reason, and a receipt |
