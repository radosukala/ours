## Failures during the build

1. **The contract check refused the conforming fixture.** The first
   version treated `layer.write("booking", { … })`'s record as a field
   list, found it was not an array of string literals, and refused it as
   undecidable. The test caught it, not inspection. Fixed by reading a
   write's record as an object literal and checking its keys against the
   declared fields — which is the better check, and a computed or spread
   key is still refused.
2. **Two batches of fixture files were written from the wrong working
   directory.** The shell's directory had moved into the fixture; one
   batch landed correctly by coincidence, the other did not land at all.
   Caught by listing the tree before continuing; rewritten with absolute
   paths. No file was written outside the mandate's scope.
3. **The first typecheck failed** on three references to a renamed
   variable in the CLI's export and verify commands. Fixed.

## Dependencies added, and why

  repository's compiler, at the same pinned version; used for the AST walk

  fooled by strings and comments, and a check that can be fooled is worse
  than none.
- `yaml` declared as a dependency of `@ours/cli` — already used through
  the kernel; declared because the CLI now writes a pin.
