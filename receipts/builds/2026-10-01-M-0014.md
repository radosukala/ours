## What went wrong on the way

- **The claims scan caught my own comment.** The comment on the status line
  said "hands over". It was reworded.
- **A server component can't call a function from a client file.** The
  button's words live in a plain module (`join.ts`) that both sides read.
- **The invite page imported FrontPage.tsx.** A guard from M-0011's
  re-check allows only the front page's route to import it, because it
  holds listed handover sentences. The lede moved to `lede.ts`.
- **A stylesheet rule with three grouped selectors** confused the rendering
  verification's CSS reader. It was written as three rules.
- **Measuring every width inside one page failed:** the app forbids
  framing. Widths were measured by resizing the browser.
- **A shell loop named its variable `path`.** In zsh that clears `PATH`, so
  one HTTP check ran with no commands. It was re-run with another name.
- **The verifiers found 2 MEDIUM and 8 LOW,** among them a button that
  promised a seat to a newcomer who would wait, and a sentence untrue for a
  suspended account. All are fixed or recorded. See the verification
  report, and D-0016 §N.
- **The re-checker found 7 LOW.** The most telling: the fix for the button
  made its words wrong for the address at the front of the line, which is
  now accepted and recorded. D-0016 §O has the rest.
- **I wrote "he" and "his" for the founder in two records,** copying older
  records. Both now say "the founder".
