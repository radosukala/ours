## The stopping rule, declared before it starts

This is the rule M-0018 used, as M-0021 asks.

1. **Two verifiers that built none of it,** each in its own worktree
   outside the main checkout (its `apps/web/.env.local` may hold real keys,
   D-0021 §F):
   - **honesty:** every sentence M-0021 added or changed, against D-0024,
     M-0021's acceptance criteria one by one, AGENTS.md and what the code
     does: the first screen's order and words; the count's truth in every
     state (read, unread, the waiting list, a member); the pledge's
     sentence listed for `FrontDoor.tsx`; the need's denial paths (too
     long, empty, control characters, with the seat request refused, with
     the gates closed), that it is kept without the address and never
     rendered, and that its count is right; the privacy notice's row and
     the kit manifest's; the card's metadata; SPEC §18.23 and the build
     receipt; `/feed`'s, the contract's and the agreement's verified words
     unchanged;
   - **rendering and use:** the first screen in a browser at 320, 375, 820,
     1000 and 1440px, light and dark, as a visitor, as a member, with no
     seat open and with seats open, with joining closed, with the database
     down; the form by keyboard and touch, each refusal at its field, the
     one answer, the needs' count appearing from the first; the link card
     as X's, Facebook's and Slack's crawlers fetch it (`og:` and
     `twitter:` tags, the image's size and bytes); nothing scrolling
     sideways; the contrast of the new parts.
2. **Their tests are committed as written,** before any fix: each finding
   is a `DEFECT` test that fails on the verified commit; each sound check a
   `closed` test that passes.
3. **Every finding is fixed or recorded.** A fixed `DEFECT` test is renamed
   *"fixed ("*; a test adapted to a fix says *"Changed after…"* and why.
4. **One re-check** by an agent that built and verified none of it.
5. **Every re-check finding is fixed or recorded,** and there is no further
   round.

**What the founder asks for is not a finding.** The first screen's words
went to the founder before the build (D-0024 §E), and screenshots go
before anything is pushed. A change the founder asks for is made under a
record before the re-check, written here, and re-checked with the rest.
