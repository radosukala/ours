# Verification — M-0016, the build kit

**Build:** `6925b1e` (the kit, the feed's manifest, `/build`) and `576df0a`
(links), under [`M-0016`](../../mandates/M-0016.md).

**Stopping rule, declared before verification starts:**

1. Two independent verifiers, neither of whom built the kit:
   - one for **honesty and rendering**: every sentence the kit, `/build`
     and the feed's manifest put in front of a person or an agent, against
     the records and against what the code does; and `/build` as a browser
     shows it;
   - one for **the tool**, adversarially: rules a project can break and
     still pass, honest projects it wrongly fails, and anything it must
     never do (reach the network, write outside the files `init` names,
     follow a link out of the project, print a secret).
2. **An agent trial:** a fresh agent, given only the line on `/build` and a
   FICTIONAL app to build, against a local production build.
3. Their tests committed as written, before any fix.
4. Fixes.
5. One re-check, by an agent that built none of it.
6. Then every finding is fixed or recorded here. There is no further round.

**Classes:** every check here is `CHECKED` (a test reports). Only `R-SCOPE`
is `ENFORCED`.

The results follow below as each step completes.
