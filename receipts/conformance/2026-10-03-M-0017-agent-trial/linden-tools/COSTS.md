# Costs

What it costs to run Linden Tools each month, and who pays. Keep it up to date (our.one rule 7).

| What | Provider | A month | Paid by |
|---|---|---|---|
| Hosting | Hetzner: a small server in Germany, which Mira already rents | 6 euros, for the whole server | Mira |
| Database | None of its own: a file on that server | 0 euros | Nobody: it isn't a separate service |
| Email, for sign-in links | Resend, free plan | 0 euros, for now | Nobody, on the free plan |
| Domain | None, for now: neighbours use the server's address | 0 euros | Nobody |
| **Total** | | 6 euros | Mira |

The maintainer's pay: none. Mira doesn't want to be paid.

Linden Tools takes no payments from the people who use it.

Before it runs for real: Resend sends email to people other than the holder of its account only from a domain verified with it. Its API answers anything else with "You can only send testing emails to your own email address" (resend.com/docs/api-reference/errors, read on 3 October 2026). So with no domain, sign-in emails can reach only Mira. A domain, or another email service, would change the costs above.
