# Dílna Libeň — a FICTIONAL community

**Every record in this directory is a sample.** The workshop, its members,
its votes, its money, and its decisions are invented, under `M-0006`, so
that the gate for community records could be built and proven before any
real community's records exist. Nobody here exists. Nothing here is a
claim about anyone.

The fixture is labelled `fictional: true` in every machine record and
`FICTIONAL` in every human source, and the kernel prints the label on every
run over this root:

```bash
pnpm ours check M-1 --root communities/dilna-fixture
pnpm ours admit communities/dilna-fixture booking --source tests/fixtures/apps/booking-ok
```

What the fixture shows: a charter as a community's root authority; standing
with a public count and a private register; three decisions, each with its
vote, checked against the charter's procedure for its class; a service
specification for an equipment-booking tool — records, articles, options,
contract, tests, transition — pinned by the decision that adopted it; and
a mandate to implement it that is denied write access to the records it is
judged by.

The first real community's records replace this fixture under `M-0005`,
after `D-0007`. Until then, this is a fixture, and it says so.
