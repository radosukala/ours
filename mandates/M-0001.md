# M-0001 — Build the Authority Trace

**Status:** TESTED — built and receipted 30 August 2026 while marked DRAFT, status corrected under `D-0004` §C on 8 September 2026
**Class:** BUILD
**Authorizing decision:** [`D-0001`](../decisions/D-0001.md)
**Machine projection:** [`M-0001.yaml`](./M-0001.yaml)

## The first self-hosted mandate

M-0000 was written by hand because the kernel did not exist. M-0001 is not.
It is validated by the kernel that M-0000 produced, before any work begins:

```bash
pnpm ours check M-0001
```

If that refuses, the work does not start. That is the whole difference
between this mandate and the one before it.

## Objective

Build a static page, generated from the records in this repository, that lets
a visitor who trusts nobody here reconstruct the authority under which the
page itself is running — and see, in the same list and at the same weight,
the articles no machine could decide.

## Human outcome

A reader who has never seen this repository can correctly answer, without
coaching: who authorised this, what the implementer was allowed to do, what
was actually checked, what was not checked, and how to reverse it.

## Adopted constraints

**Truthfulness**

- The page is a projection over the same records the verifier reads. It
  maintains no separate hand-written narrative, and no fact appears on it
  that is not derived from a record.
- It states `FOUNDER AUTHORITY` — not member authority — unmissably.
- It reports enforced and open articles in one list, at equal weight, with no
  combined total.

**Privacy and independence**

- No analytics, no tracking, no third-party script, no remote font, no cookie.
- No form, no account, no email field. Nothing is collected because nothing
  is asked.
- Static output, so that anyone can rehost it.

**Design direction, as adopted in D-0001**

- The register of an interface someone uses daily, not a campaign poster.
- A neutral UI sans for prose; a true monospace for identifiers, digests and
  states. Those are read, not looked at.
- Near-monochrome. Status is carried by typography and position, not by a
  palette of coloured pills.
- Generous whitespace; a document-like structure.
- Articles that no machine can decide carry the same visual weight as those
  that passed. No green wall.
- Accessible: real landmarks, visible focus, `prefers-reduced-motion`
  respected, and legible in both light and dark.

## Hypotheses

1. A non-technical reader understands the trace in under two minutes.
2. Rendering the open articles at equal weight reads as candour rather than
   as failure.
3. The record schemas survive the page without a breaking change.

## In scope

```text
apps/proof/**
packages/kernel/**      reading helpers only, no rule changes
tests/**
```

## Out of scope — denied

```text
authority/**
constitution/**
decisions/**
mandates/**
receipts/**
```

The page displays these records. This mandate may not edit them.

An implementer who found the trace inconvenient — a failing check, an awkward
status — could otherwise correct the page by correcting the record it reads.
That is the precise failure this project exists to prevent, so it is denied
here rather than left to good intentions.

## Acceptance tests

1. `pnpm ours check M-0001` authorises before the build begins.
2. Every value rendered on the page resolves to a record in this repository;
   no fact is hand-written into the template.
3. The page names the authority as founder bootstrap and states that no
   member institution exists.
4. Enforced and open articles appear in one list; no combined total is
   displayed anywhere.
5. The page renders with no network request to any third-party origin.
6. The page is legible in light and dark, at 375px and at desktop width.
7. A keyboard user can reach every link, with a visible focus state.
8. `pnpm typecheck` and `pnpm test` pass; the static export builds.
9. The rendered page contains no prohibited ownership claim, checked by the
   kernel's own `R-NO-FICTIONAL-OWNERSHIP` scan rather than by reading it.

## Evidence required

- the static build output and its artifact digest;
- a conformance report naming each article and its class;
- narrow-mobile and desktop inspection;
- a build receipt recording agent, model, scope touched, and failures.

## Stop conditions

- a value cannot be derived from a record and would have to be hand-written;
- an acceptance test would require weakening a constitutional article;
- the page requires a network call to render;
- implementing a rule requires inventing a fact marked `[CONFIRM]`.

## Rollback

Additive. The page is new; reversal is removing the route and the build
output, and no record it reads is modified.

**Irreversible residue: none** at build time. Note that this changes at
release: once the page is public, anyone may have read it, and that cannot be
undone. `M-0001-RELEASE` carries that residue, not this mandate.
