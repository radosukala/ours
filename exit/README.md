# Exit

Exit is not a sentence in terms of service. It is a maintained capability, and
a fork drill that has never been attempted is an aspiration.

## Today

What can be exported today is small and honest: the authority chain behind a
mandate, with its human sources embedded and hashed.

```bash
pnpm ours export M-0000
pnpm ours verify exit/bundle-M-0000.json
```

Copy the bundle to an empty directory and verify it there. It needs no
repository, no account, and no network. Generated bundles are not committed —
they are reproducible from the records in one command, and a stale committed
bundle would be a worse claim than none.

## Not yet

A real Exit Pack, once there is anything to leave, would carry source and
dependency manifests, the constitution and charters, schemas and migration
history, build instructions, a member's own data in interoperable form,
portable relationship edges where counterparties consented, public
institutional state, and the naming rules.

It must never carry another person's private data merely because a fork is
constitutionally permitted.

None of that exists. There are no members, no data, and nothing to fork.
